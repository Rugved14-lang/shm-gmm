Methodology

How It Works

A four-step pipeline transforms raw acceleration data into identified structural modes

🌊 1
Raw Vibration Data
Ambient acceleration signals from sensors on each floor of the 3-story LANL shear-frame structure.
scipy · numpy
🔊 2
Spectrum (PSD)
Welch's method with Hann windows estimates the one-sided Power Spectral Density, revealing frequency content.
welch · nperseg=2048
🔍 3
Peak Features
Prominent peaks are detected; each yields frequency f₀, log-amplitude, and damping ζ via half-power bandwidth.
find_peaks · Δf/(2f₀)
🤖 4
GMM Clustering
A Gaussian Mixture Model clusters peaks in [f₀, log-PSD, ζ] space. BIC selects the optimal component count.
GaussianMixture · BIC

The Welch PSD (cyan line) is estimated with a 2048-sample Hann window (Δf ≈ 0.098 Hz). Triangle markers (▲) indicate spectral peaks identified via prominence-based detection; each is coloured by its assigned GMM cluster / vibration mode.

🫧 GMM Cluster Scatter — Frequency × Amplitude Bubble size ∝ damping ζ

Each bubble is a detected spectral peak placed in the frequency–log-amplitude plane. Bubble size encodes the estimated damping ratio ζ. Colours correspond to GMM cluster assignments; well-separated clusters confirm distinct structural vibration modes.

📉 BIC Model Selection Curve Lower BIC = better

Bayesian Information Criterion (BIC) scores for GMM models with 1 to 6 components. The star (★) marks the optimal component count selected automatically; this balances goodness-of-fit against model complexity.

Methodology

Why GMM for Mode Identification?

Gaussian Mixture Models bring unique advantages to Operational Modal Analysis

✅ GMM Advantages

  • Data-driven mode identification — no assumed mode count
  • Probabilistic cluster assignments reflect uncertainty
  • Automatic model order selection via BIC criterion
  • Naturally groups harmonics, noise, and true modes
  • Full covariance captures correlated feature structure
  • Robust to outlier peaks via soft assignments

⚖️ Comparison with Classical OMA

  • SSI / FDD require more domain knowledge and tuning
  • GMM is fully unsupervised and scalable
  • BIC handles model order where SSI needs stabilisation diagrams
  • Compatible with any feature-rich spectral representation
  • Easier integration into automated health-monitoring pipelines
  • Uncertainty propagation is built into the probabilistic framework
